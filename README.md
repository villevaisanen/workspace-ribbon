# workspace-ribbon

Native Hyprland continuous horizontal workspace animation for Omarchy.

This branch contains the project foundation and research, with no stable release
or experimental plugin implementation. Active development is on
[`dev`](https://github.com/villevaisanen/workspace-ribbon/tree/dev), version
**0.1.0-dev**. See that branch for build instructions, configuration, compatibility
limits and the test report. The repository is initially private.
